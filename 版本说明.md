# 交付包自动组装 0.1.0

- 按项目和资料清单自动选取版本，齐全项目生成独立交付包。
- 缺件、同版本内容冲突和超出数量要求的项目列出处理事项。
- 提供中英文网页、使用说明和结果摘要。
- 网页直接处理本机文件；本机命令支持文件夹批量处理、重复运行和包内文件核对。

# Delivery Pack 0.1.0

- Select versions by project and delivery recipe, then package complete projects.
- List missing files, same-version content conflicts and excess quantities.
- Chinese and English browser interface, guides and result summaries.
- Process files in the browser, or use the local commands for folders, repeat runs and archive verification.
